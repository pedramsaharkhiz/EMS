# ADR-0012: ذخیره و API به وقت UTC؛ تاریخ شمسی فقط برای نمایش متنی

- **وضعیت:** پذیرفته‌شده
- **ثبت‌شده در:** ۲۰۲۶-۱۱-۰۷ (ثبت بازنگر؛ تصمیم پیش‌تر در کد و مستندات اجرا شده بود)

## زمینه
کاربران ایرانی تاریخ شمسی و ساعت تهران می‌بینند، ولی ذخیره و تبادل داده باید بدون ابهام منطقهٔ زمانی باشد.

## تصمیم
همهٔ `DateTime`های دیتابیس UTC هستند و API ISO 8601 با `Z` می‌دهد. تبدیل به تاریخ شمسی و ساعت تهران (`PersianDate`) فقط برای متن نمایشی (مثل Excel) انجام می‌شود، با ارقام لاتین و قالب صفرپر (`1405/08/12 14:30`) تا مرتب‌سازی متنی درست بماند.

## گزینه‌های بررسی‌شده
در مستندات و تاریخچهٔ پروژه گزینهٔ جایگزینی ثبت نشده است؛ اگر روزی بازنگری شد، گزینه‌ها همین‌جا اضافه شود.

## پیامدها
- مقایسه و مرتب‌سازی زمان‌ها بدون ابهام است.
- **هزینه:** هر کلاینتی که تاریخ را به کاربر نشان می‌دهد باید خودش به شمسی تبدیل کند (API فقط UTC می‌دهد). ایران از ۱۴۰۱ ساعت تابستانی ندارد؛ اگر این قاعده برگردد، ثابت `UTC+03:30` پشتیبان باید بازبینی شود.
